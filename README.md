## 📌 Overview

A **premium, mobile-first single-page website** for **Jai Hanuman Madugula Halwa** — a traditional Indian halwa business based in Madugula, Andhra Pradesh. The site showcases the brand's products, facilitates orders via phone/WhatsApp, and delivers a festive, devotional aesthetic aligned with the brand identity.

---

## ✨ Features

- 🌟 **Hero Section** — Glowing Telugu heading `మాడుగుల బెల్లం హల్వా` with animated deity silhouettes
- 🍯 **Product Showcase** — 3 product cards with high-quality images:
  - Special Neti Halwa (Pure Ghee Halwa)
  - Dry Fruits Halwa
  - Custom Wedding & Function Orders
- ✅ **Why Choose Us** — Trust signals with icons (Pure Ingredients, No Preservatives, Pan-India Delivery, etc.)
- 📦 **Order Section** — Prominent Call Now + WhatsApp buttons, PhonePe payment badge
- 💬 **Testimonials** — Bilingual customer reviews (Telugu & English)
- 🔗 **Footer** — Contact info, Instagram, 5-star rating
- 📱 **Floating Call Button** — Always-visible on mobile
- ✨ **Sparkle Particle Animation** — Gold/amber floating particles
- 📜 **Scroll Animations** — Fade-in-up on scroll for all sections
- 🎨 **Parallax Hero** — Subtle depth effect on scroll

## 🚀 Getting Started

### Run Locally

No build tools or dependencies required — it's pure HTML/CSS/JS.

```bash
# Clone the repository
git clone https://github.com/saahodevara/RetailShop.git
cd RetailShop

# Serve with Python (recommended)
python -m http.server 8090

# OR use Node.js
npx serve .
```

Then open **http://localhost:8090** in your browser.
